# 5hon.com 現状レポート — 2026-10-01

## 目的

5hon.com を独立サイトとして今後も維持・改善する価値があるか、2026年10月1日時点の利用状況・検索状況・収益性・技術SEOの状態から整理する。

5hon.com は、Googleドキュメントから縦書きEPUBを作れる無料ツールとして、実際に使ってくれる人がいる限りできるだけ気軽に残したい。

収益については、まず最低限の目標として、年間およそ11ドルのドメイン代を無理なく回収できる状態を目指す。それ以上の収益化を否定するものではなく、ユーザー体験を損なわない範囲で収益が増えることは歓迎する。

個別ユーザーを識別できる情報、アカウント情報、IPアドレス等は本レポートには含めない。

関連Issue: #6

## 1. 結論

2026年10月1日時点では、5hon.com をよろずコムへ統合せず、独立サイトとしてしばらく維持する価値がある。

理由は以下。

- 検索流入はまだ非常に小さいが、Google検索で実際に露出・クリックが発生している
- トップページや使い方記事は、少ない母数ながら検索結果の1ページ目に出ている
- 直近28日で `/api/generate` が16回呼ばれ、13回が200 OKだった
- 第三者が実際に5hon.comでEPUBを作って公開した事例も確認できた
- 年間の独自ドメイン維持費は約11ドルと小さい
- sitemapやURL正規化など、明白なSEO改善余地がまだ残っている

つまり「改善しても使われなかったサイト」ではなく、「小さいながら既に使われていて、まだ基本的な改善余地も残っているサイト」という段階にある。

## 7. 現在の技術SEO上の課題

### sitemap

現在の `public/robots.txt` は以下を指している。

```
Sitemap: https://5hon.com/sitemap.xml
```

しかし、このURLは404。

Astroが実際に生成しているsitemapは以下。

```
https://5hon.com/sitemap-index.xml
```

こちらには7URLが含まれている。

また、2026-10-01時点でGoogle Search Consoleに送信済みsitemapは0件。

### trailing slash / canonical

sitemap内では末尾スラッシュ付きURLが列挙されている一方、Googleが検索実績を記録しているのは主に末尾スラッシュなしURL。

現在は、例えば以下の両方が200で応答する。

- `/blog/how-to-use`
- `/blog/how-to-use/`

さらに、それぞれがself canonicalになり得る。

小規模サイトとしてはURL正規化を明確にしたほうがよい。

### Index status

Google URL Inspection確認結果:

Indexed:

- `/`
- `/blog`
- `/blog/how-to-use`
- `/blog/page-break`
- `/terms`

Crawled, currently not indexed:

- `/blog/what-is-epub`

Google未認識:

- `/privacy`

## 9. 競合環境

2026年9月には「電子出版工房 縦書き小説版」など、縦書きEPUB作成を広くカバーする無料ツールも登場している。

という短い導線にある。

今後もこの特徴を中心に維持する。

## 10. 収益について

2026年8月25日からKo-fiへの小さな支援導線を設置している。

2026年10月1日時点では、確認できる範囲で支援収益はまだ発生していない。

現状の収益目標は、まず最低限、

「年間およそ11ドルのドメイン代を回収する」

こと。

これは収益の上限ではない。ユーザー体験を邪魔しない範囲で支援・広告・その他の収益が増えることは歓迎する。

ただし、収益化のために使い勝手を悪くしたり、5hon.com の「URLを貼ってすぐEPUBを作れる」という簡単さを壊したりはしない。

## 11. 次にやること

まず、利用者向け機能を増やす前に、現在あるサイトを正しく検索エンジンへ伝える。

優先順:

1. robots.txt の sitemap URL を `/sitemap-index.xml` に修正
2. Google Search Consoleへ正しいsitemapを送信
3. trailing slash / canonical を統一
4. `/blog/what-is-epub` の未index状態を改善
5. `/blog/how-to-use` を実際の検索意図に合わせて補強
6. 4〜8週間後にSearch Consoleと `/api/generate` の利用数を再確認

大規模な新機能追加や強い収益化施策は、この結果を見てから判断する。

---

## 12. 現時点の方針

5hon.com は、少なくとも現時点では閉じたり統合したりしない。

小さくても実際に使われているなら、その人たちが引き続き使える場所として残す。

まずは技術SEOを整え、検索から必要な人へもう少し届く状態を作る。

収益面では、最低限ドメイン代を自力で賄える状態を第一目標とする。それを超えて自然に収益が伸びるなら、その分には歓迎する。
